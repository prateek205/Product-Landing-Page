# 📱 Mobile Product Landing Page

A responsive **Mobile Store Product Landing Page** built using **pure HTML and CSS only**.
This project showcases a modern smartphone product with a clean UI, hero banner, product features, specifications, and footer section.

The main goal of this project is to practice **layout design, flexbox, positioning, responsive design, and UI styling** without using JavaScript.

---

## 🚀 Live Preview

Example:
Live Demo: https://productlandingpageprateek.netlify.app/

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Google Fonts
* Font Awesome Icons

## 📌 Features

* Modern Hero Section with product image
* Navigation Bar
* Product Highlights
* Camera, Battery & Display sections
* Specifications Section
* Pricing Card
* Call-to-Action Button
* Footer with social links
* Fully Responsive Layout (Mobile + Tablet + Desktop)
